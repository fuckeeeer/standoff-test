# STANDOFF ТЕСТ 2 — «Насколько ты стандовчик?»

Максимально научный тест: 10 вопросов, 0 научности и 7500 часов чужого опыта.
Внутри — Вели-вайб, тиктоки, скины, токсичность и один нож, который тебе не достанется.

## Живая версия

**https://fuckeeeer.github.io/standoff-test/**

Репозиторий: **https://github.com/fuckeeeer/standoff-test**

## Как открыть

Двойной клик по `index.html`. Всё работает офлайн, без сборки, без сервера и без установки зависимостей.
Если браузер ругается — просто открой файл через «Открыть с помощью → Chrome / Edge / Firefox».

## Что внутри

- **Загрузка с капчей** «выберите все клетки, где сидит кемпер» (правильный ответ: везде).
- **10 вопросов** про кейсы, 1х1, тиммейтов, чат и, конечно, Вели.
- **5 приговоров**: ПРО С ТАЧСКРИНОМ, ВЕЛИ-МЛАДШИЙ, ТИКТОК-ФРАГГЕР, СКИН-ИНВЕСТОР, ТОКСИК-ЛЕГЕНДА.
- **MMR**, который выдуман, но всё равно обидно.
- **Шкалы** скилла, Вели-вайба, тиктока, скинов и токсичности.
- **Живой лобби-чат** с ботами, скинами и модератором, который всех удаляет.
- **Печеньки** (731 штука), фейковая реклама курса и попап «ты выиграл нож».
- **Звук**, который можно выключить (кнопка справа сверху).
- **Парти-режим**: нажми на логотип 5 раз.
- **Кнопка «Поделиться позором»** и клавиши 1–5 для ответов.

## Дисклеймер

Это пародийный сайт. Он не связан с Axlebolt, Standoff 2, Вели, ТикТоком и реальностью.
Все совпадения случайны, ножи не настоящие, MMR выдуманный, отзывы тоже.
Мы никого не хейтим — мы всех любим. Даже тебя.

Данные никуда не отправляются: только `localStorage` (попытки, звук, печеньки) и твоё чувство юмора.
